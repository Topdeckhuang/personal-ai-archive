# AI-READONLY: skills 目录索引

**本目录回答"我会什么、还差什么、打算怎么学"**。

| 文件 | ACCESS | 内容 | AI 何时读取 |
| --- | --- | --- | --- |
| [inventory.md](./inventory.md) | `ai-editable` | 已掌握技能清单（含熟练度与证据） | 判断该用什么深度解释时 |
| [gaps.md](./gaps.md) | `ai-editable` | 待提升能力清单 | 给学习/选型建议时 |
| [learning-plan.md](./learning-plan.md) | `ai-editable` | 学习计划、资源与进度 | 规划学习路径时 |

## 规则

- 三个文件均为 `ai-editable`：AI 可在确认后更新，并在 `CHANGELOG.md` 留痕；仍禁止删除历史行。
- **熟练度口径**：0 未接触 / 1 了解概念 / 2 能在指导下做 / 3 能独立完成 / 4 能教别人 / 5 领域专家。
- **要有证据**：技能条目尽量附"做过的项目/产出链接"，避免自我评价失真。

## 建议更新频率

每月一次；每次做完一个大项目后更新 `inventory.md`。
