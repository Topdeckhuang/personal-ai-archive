# AI-APPEND: 重要决策记录

> 每条记录固定五段式：**背景 → 选项 → 决定 → 理由 → 复盘**。只追加，不修改历史。
> AI 在遇到同类问题时，应先检索本文件，避免推翻已做出的决定。

## 决策模板（复制使用）

```markdown
### [YYYY-MM-DD] {{决策主题}}

- **背景**：{{当时要解决什么问题，约束是什么}}
- **选项**：A. {{}} | B. {{}} | C. {{}}
- **决定**：{{最终选择 X}}
- **理由**：{{为什么选它，放弃了什么}}
- **复盘**：{{（后续填写）实际效果如何，下次会不会改}}
- **记录者**：{{本人 / AI:XXX}}
```

### 填写示例（理解后可删除本区块）

### [2026-10-24] 个人档案放在哪里

- **背景**：希望一套档案被多个 AI 复用，不想重复粘贴
- **选项**：A. 各平台自带的 Memory | B. 本地文件夹 | C. GitHub 公开仓库
- **决定**：C（GitHub 公开仓库 + Markdown）
- **理由**：可被任意 AI 通过 URL 读取，有版本历史和回滚能力
- **复盘**：待实际使用后补充
- **记录者**：本人
