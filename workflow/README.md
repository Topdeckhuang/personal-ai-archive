# AI-READONLY: workflow 目录索引

**本目录回答"我怎么做事"**，是 AI 行为方式的直接约束来源。

## 文件清单

| 文件 | ACCESS | 内容 | AI 何时读取 |
| --- | --- | --- | --- |
| [communication-style.md](./communication-style.md) | `ai-readonly` | 语言、语气、结构化程度、禁止的表达 | **每次会话必读** |
| [priority-rules.md](./priority-rules.md) | `ai-readonly` | 任务排序规则、AI 决策与取舍原则 | 涉及规划、建议、多方案时必读 |
| [habits.md](./habits.md) | `ai-readonly` | 作息、专注时段、回复节奏 | 涉及排期、提醒时 |
| [tools.md](./tools.md) | `ai-editable` | 常用工具栈、环境版本、账号 | 涉及技术选型、命令、环境时 |

## 使用规则

- 前三个文件为 `ai-readonly`：AI 只能遵守，不能修改；认为过期请提建议。
- `tools.md` 为 `ai-editable`：AI 可在本人确认后更新条目，并在 `CHANGELOG.md` 留痕。
- 若 AI 输出与本目录冲突，**以本目录为准**（除非你在当次对话中明确推翻）。

## 填写优先级建议

1. `communication-style.md`（收益最大，立刻改变 AI 回答质感）
2. `priority-rules.md`
3. `tools.md`
4. `habits.md`
